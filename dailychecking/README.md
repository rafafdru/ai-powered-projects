# DailyChecking

DailyChecking is a PWA designed to help users manage routine medications in a simple and organized way.

Users can register medications for specific days of the week and mark them as taken using daily checkboxes.

The application keeps the weekly medication history saved throughout the week and automatically resets the check history every Monday at 00:00, without deleting the registered medications.

## Features
- Weekly medication organization
- Daily check system
- Persistent medication list
- Weekly automatic reset
- PWA support

## Technologies
- HTML
- CSS
- JavaScript
- PWA
