# Nidium

Nidium is a Progressive Web Application (PWA) focused on personal organization, productivity and weekly planning.

The platform was designed to centralize commitments, deadlines, goals, task management and weekly routines in a modern and intuitive dashboard experience.

## Overview

Nidium works as a personal productivity hub where users can organize different aspects of their routine in a single environment.

The application combines calendar management, deadline tracking, goal monitoring, kanban organization and weekly planning tools to help users maintain productivity and clarity throughout the week.

## Main Features

### Dashboard
The main dashboard summarizes the user's most important information, including:

- Delayed commitments
- Urgent deadlines
- Tasks for today
- Active goals
- Upcoming deadlines
- Weekly planning progress

### Calendar & Schedule
Users can manage appointments and commitments through a calendar-based agenda system.

Each commitment can include:
- Client name
- Description
- Date
- Time

### Deadline Management
The application includes a dedicated deadline system that automatically separates deadlines into categories such as:

- Urgent deadlines
- Delayed deadlines
- Regular deadlines

Deadlines close to expiration are visually prioritized.

### Goals System
Users can create personal goals with:

- Title
- Description
- Deadline
- Progress percentage
- Checklist tracking

### Kanban Board
Nidium includes a kanban task management system with the columns:

- Backlog
- To Do
- In Progress
- Completed

Tasks can also receive priority levels:
- Low priority
- Medium priority
- High priority

### Weekly Planning
The weekly planning system allows users to organize activities by:

- Day of the week
- Morning
- Afternoon
- Night

This creates a structured weekly productivity routine.

Nidium was developed as a Progressive Web Application, allowing:

- Installation on mobile devices
- Offline support through cache storage
- Standalone app experience
- Fast loading performance
